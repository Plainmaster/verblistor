# Verb data

`src/data/verbs.json` is generated by `npm run data:build` from:

| Source | Used for | License |
|---|---|---|
| [SALDO morphology](https://spraakbanken.gu.se/en/resources/saldom), Språkbanken Text, University of Gothenburg | inflected forms | CC BY 4.0 |
| [Swedish Kelly-list](https://spraakbanken.gu.se/en/resources/kelly), Språkbanken Text | frequency rank | CC BY-SA 3.0 |
| `data/verbs.txt`, `data/overrides.json` (this project) | selection, English glosses, levels, sentence contexts, corrections | CC BY-SA 4.0 |

`src/data/examples.json` is hand-written: one example sentence per form, reviewed by teachers in the artifact "Verblistornas exempelmeningar". The verb's words are in braces. It is merged into the verbs when the app loads, so `data:build` does not touch it. The audio is generated by the `elevenlabs-tts` voice bank (`adapters/verblistor.py`).

Because it is derived from the Kelly-list, `verbs.json` is distributed under CC BY-SA.

To rebuild from scratch:

```sh
mkdir data-raw
curl -L -o data-raw/kelly.xml  https://svn.spraakdata.gu.se/sb-arkiv/pub/lexikon/kelly/kelly.xml
curl -L -o data-raw/saldom.xml https://svn.spraakdata.gu.se/sb-arkiv/pub/lexikon/saldom/saldom.xml
npm run data:extract
npm run data:build
```

Levels are editorial (aligned with SFI course content) rather than Kelly's corpus-derived CEFR, which over-ranks web vocabulary.
Group is never hand-entered: `classify()` derives it from the forms, and the test suite re-checks every verb.
